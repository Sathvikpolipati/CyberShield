🚀 Installation & Setup Guide
🪟 Windows Setup (PowerShell / CMD / VS Code) Python 3.9+

Run the following commands in PowerShell or Windows Terminal to clone and start CyberShield:

# 1. Clone repository git clone https://github.com/Sathvikpolipati/CyberShield.git cd CyberShield # 2. Create and activate Python virtual environment python -m venv venv .\venv\Scripts\activate # 3. Install dependencies pip install -r requirements.txt # 4. Launch CyberShield Web Dashboard: python run_web.py # Open http://localhost:8000 in your browser # Or launch the interactive Terminal TUI: python run_tui.py
🐧 Linux Setup (Ubuntu / Debian / Kali / Arch) Root Privileges

Install dependencies and run CyberShield with root elevation for raw socket sniffing and iptables:

# 1. Install prerequisites sudo apt update && sudo apt install -y python3 python3-pip python3-venv libpcap-dev # 2. Clone repository & setup virtual environment git clone https://github.com/Sathvikpolipati/CyberShield.git cd CyberShield python3 -m venv venv source venv/bin/activate pip install -r requirements.txt # 3. Launch Web Dashboard with root privileges: sudo ./venv/bin/python run_web.py # Open http://localhost:8000
📱 Android Termux Setup (1-Click Installer) ARM64 / Termux

Automated 1-click installer configured for touch controls and mobile SOC telemetry:

# 1. Clone repository in Termux git clone https://github.com/Sathvikpolipati/CyberShield.git cd CyberShield # 2. Make installer executable and run chmod +x termux_setup.sh ./termux_setup.sh
🍎 macOS Setup (Apple Silicon / Intel) macOS 12+

Set up virtual environment and launch CyberShield with sudo elevation:

# 1. Clone repository & setup git clone https://github.com/Sathvikpolipati/CyberShield.git cd CyberShield python3 -m venv venv source venv/bin/activate pip install -r requirements.txt # 2. Run CyberShield Web Dashboard: sudo ./venv/bin/python run_web.py

Architecture

How CyberShield works

A five-stage pipeline from raw bytes to blocked threats — running live in your network.

1
Stage 1 · Capture
Zero-Driver Packet Capture
The native socket sniffer binds directly to your NIC using raw socket telemetry — zero kernel drivers, zero external dependencies.
2
Stage 2 · Parse
Deep Packet Inspection & Protocol Parsing
Each packet is parsed into a typed PacketSummary model: IPs, ports, TCP flags, TTL, DNS queries, HTTP paths, and hex previews in microseconds.
3
Stage 3 · Analyze
4-Engine Threat Detection Pipeline
The DetectionEngine executes Port Scan, SYN Flood, ICMP Sweep, and DNS Tunnel detectors in parallel with instant alert propagation.
4
Stage 4 · Broadcast
250ms WebSocket Broadcast Cycle
An asyncio broadcast task delivers telemetry payloads to connected SOC clients every 250ms with zero event-loop blocking.
5
Stage 5 · Mitigate
Automated & Manual IP Firewall Block
Flagged malicious IPs are blocked via system firewall rules or manually from the dashboard with one click.
