# CyberShield Chrome Web Extension (Manifest V3)

This extension provides a lightweight quick-access monitor for your desktop browser or Android mobile browser (via Kiwi / Lemur / Yandex Browser).

## How to Install in Desktop Chrome / Edge:
1. Open `chrome://extensions` in Google Chrome (or `edge://extensions` in Microsoft Edge).
2. Enable **Developer mode** toggle in the top-right corner.
3. Click **Load unpacked** and select the `extension/` directory.
4. The CyberShield shield icon will appear in your browser toolbar!

## How to Install on Android Phone:
1. Download **Kiwi Browser** or **Lemur Browser** from the Google Play Store (these Chromium browsers support standard Chrome extensions).
2. Open `chrome://extensions` inside Kiwi Browser.
3. Enable Developer Mode & select the extension folder to load it on mobile.
